# aleksiuno.github.io

Personal site of Darius Aleksiūnas — backend developer (PHP, Symfony, ecommerce platforms).
Live at <https://aleksiuno.github.io>.

Plain HTML and CSS, served straight from this repository by GitHub Pages. No framework,
no build step, no JavaScript.

- `index.html` — the page; all content lives here
- `assets/css/site.css` — the only stylesheet: custom properties, light and dark via `prefers-color-scheme`
- `assets/fonts/` — Fraunces, self-hosted (SIL Open Font License, see `OFL.txt`)
- `assets/img/` — icons
- `CVDariusAleksiunas.pdf` — the CV linked from the page

Preview locally by opening `index.html` in a browser, or run `python3 -m http.server`
and visit <http://localhost:8000>.
